## 2. 指標與證據等級

- **官方真值評估**：`val_run_log.json` 的 Top-1。官方 harness 只對整體驗證串流計算準確率；逐張真值與分窗準確率沒有透過方法介面提供。
- **模型預測代理指標**：信心為 softmax 最大值；預測熵為 `-sum(p log p)`（nat）；預測類別熵為窗口類別頻率的 Shannon entropy（bit）；最大類別占比為窗口最常見預測類別數除以窗口大小；相鄰同類率為窗口內連續兩張的預測類別相同次數除以相鄰配對數；獨立同類率估計為該窗口 `sum(p_c²)`。這些是模型預測，不是真實類別分布。
- **輸入代理指標**：亮度代理為正規化後整張 tensor 的元素平均；對比代理為該 tensor 的元素標準差；水平差分為相鄰水平像素絕對差的平均。三者都在**正規化 tensor 空間**，不能直接當作原始 RGB 亮度、對比或 corruption 類型。
- **推測**：外觀或預測統計變動可能表示領域偏移或資料排序相關；不能由此判定 corruption 名稱、分窗準確率或 TTA 退化。

## 3. 結果

`source` 使用 eval 模式與 `torch.no_grad()`，不更新模型參數或 BN 統計。官方 Top-1 為 **0.5454545 = 1,152/2,112**；harness 記錄的串流時間 **2.7 秒**、`nvidia-smi` 峰值 **706 MiB**、PyTorch 最大 reserved **540 MiB**。這是 GTX 1080 Ti 上的數字，不代表 RTX 3090 的正式 12,288 張測試可在 90 秒內完成。`source_diag` 為 0.5454545、2.6 秒、706 MiB；兩次短跑的時間差不具意義。

### 尚未取得的合法觀察

- 官方只公布整體 Top-1，不能從目前方法介面取得逐張真實標籤。因此無分窗準確率、真實類別轉移、真值支持的長串流退化判斷，也尚無 Q4 所需的逐張正誤對照。若 Q4 必須從驗證集產圖，請先向助教確認允許的逐張評估輸出方式；不得自行讀 `data/val/labels.csv` 或影像。
- 尚未實作或試跑 TTA 候選方法，故沒有 TTA 相對固定基準的後段變化，也不能宣稱災難性遺忘。正式方法選擇須等論文候選與合規性查核。
- private 測試影像劣化類型與 public 不同；上述驗證現象只用於安排方法優先順序，不保證泛化。
