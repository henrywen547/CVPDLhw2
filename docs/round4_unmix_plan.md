# Round 4: normalization robustness after public feedback

The user reported public **0.76822** for eight-view BN and **0.76627** for ten-view paired BN. Their official validation scores were .815341 and .834754, respectively. Thus the deeper/paired setting improved validation but scored slightly worse on the observed public subset. The root `submission.csv` has been switched to the eight-view method, which also took 87.3 seconds on the local GTX 1080 Ti. Private accuracy and RTX 3090 runtime remain unknown.

The next candidate is **UnMix-TNS**, Tomar et al., ICLR 2024, [paper](https://openreview.net/forum?id=xyxU99Nutg), [author repository](https://github.com/devavratTomar/unmixtns). It targets test-time BN under temporally correlated labels, matching the observed correlation of **predicted** labels in our validation diagnostics. That diagnostic does not prove true-label correlation; the paper motivates an experiment, not an expected gain.

Implement the paper's normalization equations independently in `starter/unmix_tns.py`, without copying the author repository, loading extra weights, using source images, or modifying the official harness. Every source BN layer becomes a source-statistics-initialized K=16 mixture. Use the paper's α=.5, cosine assignment temperature .07, and component momentum derived from λ₀=.1 at batch size 64. Instance feature statistics and component assignments are computed only from the current served batch. Components update after computing the current output. This first candidate is **normalization-only**: no optimizer-based combination with Tent and no multiview ensemble. Therefore it tests a component of UnMix-TNS, not a full reproduction of every paper configuration.

Run the official validation stream from the supplied checkpoint, seed 0, with diagnostics off. Record overall Top-1, full harness time, peak VRAM, and prediction disagreement with `bn_batch`. Only add a multiview combination if the normalization-only result is materially promising and its cost leaves headroom for the RTX 3090 90-second limit. Preserve both existing test artifacts and the current `submission.csv` until official validation supports a new selection.
